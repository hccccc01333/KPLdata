# 模型卡 · 实时胜率估算（V11 → V4 阶段四修订）

> 作用：在任何展示胜率的地方，先讲清楚它是什么、不是什么。
> 面向读者：产品页访客 / 面试官 / 未来的自己。

## 1. 用途与边界

| 项 | 内容 |
|---|---|
| 用途 | 单局进行中的胜率估算（camp1 视角），用于复盘、展示与「金差护栏」提示 |
| 不是 | 不是官方预测，不是下注依据，不是「谁更强」的结论 |
| 输入 | 局内快照（金币/击杀/推塔/资源/选手经济）+ 历史队伍强弱先验 |
| 输出 | 0–1 概率 + top 因子 + 低置信标记 |
| 更新方式 | 比赛日 0.1–1s 采集快照，边采边算 |

## 2. 数据与切分（V12 已硬隔离）

- 训练数据：`data/history` 全量逐局数据（2019–2026，11k+ 局）+ `data/analysis` 宽表；
- **切分方式：按时间、按整局切三段，互不重叠**（`split_train_calib_test`）：

  | 段 | 局数 | 快照 | 用途 |
  |---|---|---|---|
  | train | 145 | 4,638 | 拟合基模型（early RF / midlate voting） |
  | calib | 20 | 548 | **只**拟合校准器、选 early clip、选校准器方法（isotonic/Platt） |
  | test | 20 | 582 | **只**报指标，训练与校准都碰不到 |

  切分按时间而非随机：局内快照高度相关，随机切会让同一局相邻帧分落 train/test。

- 旧版的问题（2026-10-18 已修）：只有一段 8 局 holdout，校准器、early clip、校准器方法
  全在这 8 局上拟合，再用同一批 8 局报指标——样本内校准 + 选择偏差同向叠加。
- 模型选型（LR/RF/ET/GBDT 与投票权重）仍在 train 段内部用 GroupShuffleSplit 做，属训练内流程，不进 calib/test。

## 3. 指标口径（站点怎么展示）

| 口径 | 定义 | 用途 |
|---|---|---|
| 固定时间点命中率 | 取「第 8 / 12 / 16 分钟及之前最后一帧」的预测与最终胜方比对 | 可信口径，页面主指标 |
| Brier | 预测概率与结果（1/0）的均方误差，越小越好 | 校准质量，配合命中率看 |
| 最后一帧命中率 | 收官前最后一帧 | 仅作对照：接近 100% 是口径使然，不是能力 |
| 分阶段回测 | early ≤8′ / mid 9–15′ / late 16′+ | 展示「越往后越难」的诚实曲线 |
| AUC | 正例排在负例之前的概率（排序质量） | **只认 test 段的 AUC**；`train_status.json` 里的 `auc`（≈0.936）是 train 段内诊断分，勿混用 |

> AUC 口径说明：站点 `assets/data.js` 的 `model.auc` 取自 `backtest_v9_report.json` 的 `holdout_real.all.auc`
> （test 20 局 / 298 帧，训练与校准都没碰过）；训练段诊断分另存 `model.trainDiagAuc` 并注明口径。

样本量提示：直播预测档案目前 158 局（8′ 时点 n=151、12′ n=154、16′ n=158，差值是部分局缺少该时点前的帧）。
这 158 是**局数**不是帧数；回测那 298 是**帧数**、对应 20 局。两个数不能混着说。

## 4. 已知偏差与风险

1. 重放 ≠ 当时：没有直播预测记录的对局，站点胜率由当前模型赛后重放得到。实测部分回补局不稳定（4 分钟内 0.02 → 0.19 → 0.80，而金差仅 ±200）。
   - 处置：优先使用直播期 CSV；重放结果标注「胜率=赛后重放」并给黄色警示条；
   - 待办：重放链路特征对齐仍需排查。
2. 早期样本少：开局可用信息少，置信度低；快照自带 `low_confidence`，页面提示「波动不代表局势剧变」。
3. **early 在翻盘局上反向自信**（V12 新增，最重要的一个）：test 20 局里 6 局是翻盘局，
   early 阶段在这 6 局上 Brier 0.416 / 准确率 0.146（**低于随机**），其余 14 局是 0.151 / 0.798。
   说明 early 专家基本是「跟经济差走」，而翻盘局的本质就是经济差不代表结果。
   这不是调阈值能修的，需要 early 阶段引入「翻盘先验」（落后方阵容/资源结构/战队逆转率）。
4. 落后方翻盘区：金差护栏会在经济差距极大时压制离谱输出，属于兜底而非校准。
5. 版本差：跨年份的英雄/版本变化没有显式建模，长周期对比需谨慎。
6. BP 工作台的概率不是这个模型：它用启发式边际（先验收缩 + log-odds 相加），页脚已写明权重，不可与模型胜率混为一谈。
7. **直播档案 ≠ 当前模型**（V12 已量化）：178 局 / 2,501 个对齐帧上，
   直播口径 Brier **0.217**，重放（当前模型）**0.134**，差 **−0.083**；方向一致率只有 **80.2%**，
   即每 5 帧就有 1 帧两边看好不同的队。
   在 test 20 局（模型没见过）上差距更大：**0.305 vs 0.178，−0.127**——所以这不是"重放背答案"，
   而是当时的直播预测确实更差。
   但两个原因分不开：① 当时的模型更旧；② 实时链路有延迟（lag_sec p90 ≈ 18s）、快照可能不全。
   **2026-10-18 起预测 CSV 增加 `model_version` / `model_trained_at` 两列**，下一批数据就能把这两件事拆开。

## 5. 不可用场景

- 赛前预测（本模型面向局内）；
- 跨版本、跨赛制的强弱比较；
- 任何需要「因果解释」的分析（事件与胜率变化只能给时间邻接证据）；
- 商业 / 博彩用途。
