## PRD 固定模板（九章）

每份 `Pxx-*.md` 均含：

1. 产品定位  
2. 用户故事（≥5，含验收）  
3. 信息架构 & UI（含 mermaid 线框 + 空/载/错态）  
4. 关键指标与统计方法  
5. 数据源（主/辅/缺口；交叉 [数据字典](../数据字典.md) / [接口逆向笔记](../接口逆向笔记.md)）  
6. 算法与 AI  
7. 与竞品差异  
8. 实现优先级（P0/P1/P2 + 现有代码锚点）  
9. 验收清单（数据 / 性能 / 视觉）

## 指标口径（全局强制）

所有指标卡 / 图表必须标注来源标签，定义见 [00-术语表.md](./00-术语表.md)：

| 标签 | 含义 |
|------|------|
| **官方** | 腾讯 leaguesite / 营地等官方字段或官方榜单原样展示 |
| **代理** | 由官方可观测字段推导的统计代理（如参团、Buff 控率） |
| **估算** | 模型或实验差分估计，带置信区间，禁止伪装成官方 |
| **舆情** | 社媒/弹幕文本与情感；与战绩分区，不进默认胜率特征 |

**P19 特别约束**：入侵 / 开团 / 支援 **不以选手视角视频 CV 为主路径**；分层展示 L1 官方口径 → L2 代理 → L3 实验估算。

**P15 特别约束**：赛后舆情任务按大场键落盘 **`data/sentiment/{match_id}/`**；小红书仅半自动分层，不做「全站实时」承诺。
