> **用途**：产品文档、UI 文案、指标卡片标签的统一口径。  
> **强制规则**：指标卡必须带**数据来源标签**（官方 / 代理 / 估算 / 舆情）；禁止把代理或估算指标标成「官方」。

## 2. 赛事层级：league / match / battle

官方接口三层结构（权威说明见 [数据字典](../数据字典.md)）：

```text
league  →  match  →  battle
赛事        大场(BO)    单局
```

| 术语 | 英文键 | 定义 | 示例 |
|------|--------|------|------|
| **赛事 / 联赛** | `league_id` | 一个赛季或杯赛容器 | `20260002` |
| **大场 / 系列赛** | `match_id` | 两队之间的一场 BO（含多局） | `2026042501` |
| **单局 / 对局** | `battle_id` | BO 中的一局；胜率、快照、复盘主键 | `736117264_10_1777089898` |
| **局序号** | `battle_seq` / `game_no` | 该局在 BO 中的第几局 | 第 1 局、第 2 局 |
| **阵营** | `camp` / `camp1` / `camp2` | `1`=蓝方，`2`=红方 | UI 展示用战队名，内部用 camp |

### 产品文案约定

| 场景 | 应用语 | 禁用 |
|------|--------|------|
| 赛程列表 | 「大场 / 系列赛」 | 勿把 match 叫成「单局」 |
| 实时中控、复盘 | 「单局 / 第 N 局」 | 勿把 battle 叫成「比赛日」 |
| 胜率曲线主键 | `battle_id` | 勿用可构造猜测的 ID 代替赛程拉取 |

> **关键约束**（数据字典结论）：`battle_id` 第三段**不能**假设为简单递增；**禁止批量构造 battle_id**，必须从赛程接口（`matches/open` → `match/battles/open`）获取。早期接口笔记中「可生成 URL」的猜想**不作为产品采集承诺**。

## 3. 数据来源标签（UI 强制）

所有指标卡片、图表标题旁、导出报告表头，必须标注以下之一（可组合）：

| 标签 | 中文展示 | 含义 | 可信度默认 |
|------|----------|------|------------|
| **官方** | `官方` | 直接来自腾讯 KPL 公开赛事接口字段，或官方页面公示榜单原文 | 最高 |
| **营地** | `营地` | 王者营地 / 掌上王者荣耀等官方系 App 公开数据（若接入） | 高（需声明版本） |
| **代理** | `代理` | 用可观测字段推导的行为/节奏指标，非官方同名字段 | 中（需写公式） |
| **估算** | `估算` | 模型输出、统计估计、置信区间、蒙特卡洛结果 | 中–低（需写方法） |
| **舆情** | `舆情` | 社交平台文本、弹幕、情感与话题，非战绩事实 | 独立维度，不与胜负混标 |
| **百科/人工** | `百科` / `人工` | 维基式档案、人工补录元数据 | 低–中（需时间戳） |

### 三层行为指标口径（入侵 / 开团 / 支援）

详见 [P19](./P19-行为指标-入侵开团支援.md)。术语层强制：

| 层 | 名称 | 定义 | UI 标签 |
|----|------|------|---------|
| **L1** | 官方口径层 | 官方反野/支援/开团等榜单或接口原文 | `官方` |
| **L2** | 统计代理层 | Buff 控率、参团、跨线参与等代理分 | `代理` |
| **L3** | 实验估计层 | 事件流差分、行为标签模型分 | `估算` |

- **禁止**：把 L2/L3 标成「官方开团数据」。
- **禁止**：把「选手视角视频 CV」写成默认交付路径（可作为长期实验备注）。

## 4. 数据生命周期：raw / clean / quarantine

| 术语 | 路径约定 | 定义 |
|------|----------|------|
| **raw / 原始快照** | `data/realtime/raw_snapshots/{battle_id}/` | 监控采集落盘的原始 JSON；**永不删除、不覆写为训练真源** |
| **live 快照** | 非 `backfill_*` 前缀文件 | 赛中实时拉取的快照 |
| **backfill 快照** | `backfill_*.json` | 赛后或补偿拉取；可作补全，单独计入质量规则 |
| **clean** | `data/realtime/datasets/clean/` | 通过质量门禁的局；**训练与回测默认集** |
| **quarantine** | `data/realtime/datasets/quarantine/` | 未过门禁的局；可诊断、可展示，但默认不进训练 |
| **manifest** | `clean_manifest.csv` / `quarantine_manifest.csv` | 分桶清单与原因字段 `reasons` |

### clean 门禁（与现行分类脚本对齐，产品口径）

满足以下**全部**才可标 clean（细节以 `scripts/classify_realtime_battles.py` 为准）：

- 有效可解析快照数 ≥ 阈值（当前 ≥ 5）
- 覆盖分钟桶数 ≥ 阈值（当前 ≥ 8）
- 有明确 `win_camp` ∈ {1,2}
- 非「仅有 backfill、无 live」的空洞局
- 时钟基本单调（回跳不超过阈值）
- 坏 JSON 占比不过高

任一失败 → **quarantine**，并记录 `reasons`（如 `too_few_snaps`、`missing_win_camp`、`clock_backjump`、`backfill_only`）。

### 产品展示约定

| 场景 | 默认数据桶 |
|------|------------|
| 模型训练 / 回测 / 验收门禁 | clean |
| 实时中控（正在进行） | live raw（尚未分桶） |
| 运维诊断 | quarantine + reasons |
| 教练复盘列表 | 优先 clean；quarantine 需显式角标 |

## 5. 解析与特征

| 术语 | 定义 |
|------|------|
| **parse_snapshot** | `kpl_official_core.parse_snapshot`：将官方 `battle/open` 的 `data` 转为统一快照字典 |
| **FeatureBuilder** | 训练与线上共用的特征构建器；因果、无泄漏 |
| **赛前特征** | BP 结束或开赛前可知字段（阵容、历史胜率先验等） |
| **赛中特征** | 当前快照时刻可知的累积量（经济、击杀、塔、龙等） |
| **泄漏 / leakage** | 用终局才知字段预测「当时」胜率；产品与模型均禁止 |
| **金差护栏** | 当经济明显落后却报高胜率时的一致性夹逼规则 |

## 6. 胜率相关

| 术语 | 定义 | 标签 |
|------|------|------|
| **自研胜率 / 平台胜率** | 本系统模型输出的 `camp1_win_prob` / `camp2_win_prob` | `估算` |
| **官方胜率** | 官方页面或接口若提供的胜率/热度类字段（若无则标「暂无官方同源」） | `官方` |
| **校准（calibration）** | 使预测频率接近真实频率；指标含 ECE、Brier | 方法说明归属算法文档 |
| **Brier** | 概率预测均方误差；主评估指标之一 | — |
| **ECE** | 期望校准误差 | — |
| **方向正确率** | 预测优势方是否与最终胜方一致 | — |
| **early / mid / late** | 赛段切片：通常 early ≤8′，mid 9–15′，late 其后（以模型配置为准） | UI 需写清分钟定义 |
| **拐点 / turning point** | 胜率或关键差分在短窗内大幅摆动的时刻 | `估算`（检测规则产物） |

## 9. 舆情与弹幕

| 术语 | 定义 |
|------|------|
| **舆情任务** | 大场结束后触发的话题/情感聚合作业 |
| **弹幕序列** | 按时间戳的文本流（如 B 站直播间） |
| **情感分** | 文本情感模型输出，标签 `舆情`，**不是**战绩 |
| **采样偏差** | 平台可见样本不等于全体观众意见；报告必须声明 |
| **半自动补录** | 强反爬源（如小红书）允许检索 API + 人工粘贴，禁止承诺「全站实时」 |

落盘约定：`data/sentiment/{match_id}/`（大场粒度关联赛程）。

## 12. 状态机（实时监控）

产品文案可映射监控状态（实现见 `official_match_monitor`）：

| 状态（概念） | 含义 |
|--------------|------|
| 等待赛程 | 尚无今日/目标 match |
| 等待开赛 | 已有 match，未进入可采 battle |
| 采集中 | 正在写 live 快照与预测时间线 |
| 局间等待 | BO 中一局结束，等待下一局 |
| 已结束 | 大场或目标局完成 |

2. 字段语义以 [数据字典](../数据字典.md) 为准；若与早期笔记冲突，**以数据字典 + 现行代码**为准，并回写修订说明。
