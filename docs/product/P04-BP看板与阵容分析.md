## 1. 产品定位

**一句话**：把官方 `bp_list` 还原为可视化 BP 时间线与双方最终阵容，并叠加历史胜率/组合强度，服务教练赛前准备与赛后 BP 复盘。

**目标用户**

| 角色 | 核心诉求 |
|------|----------|
| 教练组 | 看清 ban 掉谁、抢谁、阵容优劣势与对位风险 |
| 数据分析师 | 统计英雄出场、ban 率、组合共现与胜率（含 CI） |
| KPI / 运营 | BP 动画素材、版本 Meta 选题 |

## 3. 信息架构 & UI

### 3.1 页面区块

1. **对阵头**：队伍、局数、版本/赛段  
2. **BP 时间线（主）**：20 格步进条（Ban 红 / Pick 青）  
3. **双方阵容板**：5 分路卡片  
4. **右栏指标**：阵容胜率、相似度对手历史、风险标签  
5. **下方**：本局英雄 vs 赛段 ban/pick 率对照表  
6. **入口**：打开 P16 模拟器（换成某 ban）

### 3.2 Mermaid 线框

```mermaid
flowchart TB
  Head[对阵头·赛段/局数]
  subgraph Main [主区]
    Timeline[BP 20 步时间线]
    Boards[蓝方阵容板 | 红方阵容板]
  end
  subgraph Side [右栏]
    WR[阵容胜率+CI]
    Risk[对位风险标签]
    Meta[赛段 Ban率对照]
  end
  Table[BP 明细表·可导出]
  Sim[打开 P16 模拟器]
  Head --> Timeline --> Boards
  Boards --> Side
  Timeline --> Table
  Side --> Sim
```

### 3.3 状态设计

| 状态 | 表现 |
|------|------|
| 无 `bp_list` | 空态：本局无 BP 字段；检查 raw |
| BP 不完整 | 警告：步数 ≠20；仍渲染已有步 |
| 小样本阵容 | 胜率卡标「n&lt;20 · 仅供参考」 |
| 加载 Meta | 右栏 skeleton |

## 4. 关键指标与统计方法

| 指标 | 定义 | 窗口 | 公式 / 方法 | 置信/显著性 |
|------|------|------|-------------|-------------|
| Ban 率 | 英雄被 ban 局数 / 总局数 | 赛段/补丁 | \(k/n\) | Wilson 95% CI |
| Pick 率 | 出场局数 / 总局数 | 同上 | \(k/n\) | 同上 |
| 胜率 | 使用方获胜比例 | 同上 | \(w/k\) | 同上；n 展示 |
| 阵容胜率 | 五英雄集合（无序）同现胜率 | 滚动 N 局 | 精确匹配；回退「核心 3 英雄」 | 多重回退需标注匹配层级 |
| 先手价值 | 蓝/红胜率差 | 同窗口 | \(\hat p_{blue}-\hat p_{red}\) | 两比例 z 检验（待建） |
| BP 阶段 | 索引 0–19 映射 | 单局 | 见数据字典四阶段 | 顺序需多样本校验 |

**KPL BP 阶段（文档约定，来自样本归纳）**

```
0–3   一阶段 ban
4–9   一阶段 pick
10–13 二阶段 ban
14–19 二阶段 pick
```

## 9. 验收清单

**数据正确性**

- [ ] 20 步顺序与 raw 一致；抽样 ≥30 局  
- [ ] 阵容板英雄 = 选手最终英雄  
- [ ] 胜率 n、CI 与后端聚合一致  

**性能**

- [ ] 单局 BP 渲染 &lt; 100ms  
- [ ] 赛段 Meta 预聚合，查询 &lt; 500ms  

**视觉**

- [ ] Ban/Pick 颜色编码一致；分路对齐  
- [ ] 小样本强制视觉降权
